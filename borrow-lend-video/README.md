# Borrow vs Lend – Fluent English (30 s vertical video)

Everything is generated by code: illustrated canvas animation (1080×1920), Web Audio music + sound effects, and speech via the browser's speech synthesis. No uploaded audio, API keys or paid voices.

## Preview
Open `index.html` in Chrome/Edge/Safari (double-click is fine). Controls: **Start** (unlocks audio), Pause, Replay, Mute, Spanish/English voice selectors, **Off / Captions / Captions + IPA** (saved in localStorage). Keys: `P` pause, `R` replay, `M` mute.
Scene changes follow *actual* speech completion; the 4-second practice pause is fixed and silent (ring only, music ducked to ~-47 dB). It is not speech recognition – nothing is marked correct.

## Files
- `js/config.js` script, beats, IPA, timing · `js/draw.js` renderer (characters, 5-finger hands, book/pen, arrow) · `js/audio.js` music + SFX + ducking · `js/speech.js` voices · `js/player.js` live timeline · `js/ui.js` controls/recording
- `export/export.mjs` flattened-video exporter · `tools/` asset builder and screenshot helpers
- `output/` three MP4s (no captions / captions / captions + IPA), `timeline.json`, `audio_music_sfx_only.m4a`
- `caption.txt` cover text + suggested caption

## Export (what is real, what is not)
`node export/export.mjs` (needs Node, Playwright+Chromium, ffmpeg, espeak-ng) renders every frame with the same draw code, renders music/SFX offline with the same Web Audio code, and burns the chosen caption mode into each MP4 (an MP4 has no buttons).
**Limitation:** browser speech synthesis cannot be captured by a canvas recording or an offline render. The MP4s in `output/` therefore use **espeak-ng stand-in voices (robotic)** for narration; music, effects, ducking and timing are the real ones. Measured in the delivered file: AAC stereo, ~29.75 s, peak -0.4 dB (no clipping), practice pause ≈ -47 dB.
For a release video with natural voices, either:
1. In Chrome/Edge desktop open `index.html`, pick voices, click **Record this tab with audio**, choose *This tab* and tick *Share tab audio*; play the file to confirm voices were captured (untested here – depends on browser/OS). Convert if needed: `ffmpeg -i in.webm -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac out.mp4`.
2. Or record each narration line from any TTS you like to `voices/<beatId>.wav` (`hook, borrowAsk, borrowNarr, lendAsk, lendNarr, speakPrompt, reveal, cta`) and run `node export/export.mjs --voices-dir voices`; timing adapts to the clip lengths.

## Teaching accuracy / honesty notes
- The book always travels Alex → Sam. *Borrow* = Sam's (receiver's) viewpoint, *Lend* = Alex's (giver's); the arrow head sits above the real book. The rewind uses a labelled "OTRA VEZ" transition and hides the arrow.
- IPA (General American, Oxford-Learner's-American style) was hand-prepared; **not verified against a live dictionary** (no access in the build environment). English words inside Spanish narration use the English voice.
- Not verified here: real device voices (the sandbox has none) and the in-page recorder.
