# Audio

| Path | What |
|------|------|
| `es_hook.wav` … `es_cta.wav` (7 files) | Narration clips, synthesised locally by `voice/build_narration.py` (Piper es-MX + Kokoro en-US). `narration_report.json` logs duration, level and what speech-to-text heard. |
| `manifest.json` | clip id → file (the preview and export load these) |
| `clip_marks.json` | speech runs per clip (used to place caption splits / word highlights) |
| `export/soundtrack.wav` | **final mix** (narration + music + ambience + effects, −16 LUFS) muxed into the MP4s |
| `export/stem_*.wav`, `mix_raw.wav` | the four independent layers and the un-normalised mix (regenerated by `node scripts/render_audio.mjs`; git-ignored) |

Music, ambience and effects are **not files**: they are synthesised by `src/soundtrack.js` every time (≈8 s). To change the narration, edit the text in `voice/build_narration.py`, run it, then `bash scripts/finish_with_audio.sh`.
To use your own recorded narration instead, replace the seven WAVs (same names) and update the clip `start`/`dur` in `src/timeline.js`.
