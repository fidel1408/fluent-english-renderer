# May, Might, and Could — an interactive 60-minute class for Fluent English

An animated, code-built lesson for **adult English learners**, designed for a teacher sharing a screen on Zoom.
Everything on screen (characters, scenes, diagrams, speech bubbles) is drawn in code (SVG + CSS + JavaScript).
No AI-generated images are used. The only bitmap is the authentic Fluent English logo.

## Open it

| File | Use |
|---|---|
| `release/index.html` | The lesson. Open it in Chrome, Edge, or Firefox. Needs the `release/audio/` folder next to it. |
| `release/may-might-could-standalone.html` | The same lesson as **one file** (audio embedded, 5.9 MB). Copy it anywhere and open it. |

1. Open the file and press **Start Class Mode** (or **Start Demo Mode**). Sound begins only after that click.
2. Press **F** for fullscreen. In Zoom, choose *Share Screen* and tick *Share computer sound* so learners hear the narration.
3. Move the mouse to show the control bar; it hides itself while the lesson plays.

Nothing is rendered ahead of time and nothing runs on a server. All animation is drawn live in **your** browser, using
roughly one CPU core. The animation loop stops when the lesson is paused.

## Two modes (clearly different)

* **Class Mode** — plays each narrated scene, then **stops at the activity** and waits for you. A countdown shows the planned time.
  You can pause, restart, skip, or add one minute (+1). When time is up, it keeps waiting until you press *Continue*.
  Class Mode can run longer than one hour, because your pauses and extra discussion are real.
* **Demo Mode** — follows the planned 60:00 automatically. Activity windows run for their planned time, model answers are
  revealed on a schedule, and the lesson moves on by itself.

The top-right clock shows **Lesson plan** time (where you are in the 60:00 plan) separately from **Actual** time
(real time since you started, including pauses) and the difference between them.

### Controls

Play/pause · previous/next chapter · timeline seek (click or drag) · back/forward 5 s · replay this example · continue to next step ·
Class/Demo switch · narration on/off · sound panel (separate narration / music-and-ambience / effects volume and mute) · fullscreen ·
restart (with confirmation).
Keyboard: `Space` play/pause, `←` `→` ±5 s, `PgUp` `PgDn` chapters, `R` replay, `N` next step, `M` narration, `F` fullscreen.

## What it teaches (and what it deliberately does not)

* **Core:** present and future possibility with *may, might, could*: possible, not certain. Meaning is shown with branching
  futures built from evidence (clouds, a late van, an empty chair), not with percentages.
* *She may / might / could arrive early.* are all taught as natural. Where several modals fit, the question is multi-answer and every
  valid choice is accepted. *Might* may sound a little more tentative in some contexts, but the lesson says plainly that this is **not** a fixed ladder.
* Form: subject + modal + base verb; no third-person -s, no *to*, no *do/does/did*; modal + subject + base verb for questions;
  modal + *not* + base verb for uncertain negatives; *be* (*He might be at home.*).
* Natural questions: *Could this be the right address? Do you think she might come? What could happen next?* The lesson explains why *do*
  is correct in *Do you think she might come?* (it belongs to *think*) and why *Does she might come?* is still wrong. It does not teach
  *May it rain tomorrow?* as an everyday question.
* *Couldn't* is taught as inability or impossibility, **not** a substitute for *may not / might not*, and not as always past.
* Permission vs possibility (*You may not enter.* / *She may not arrive today.*) and *could* for past ability, polite permission, and polite
  requests are shown as brief contrasts. Perfect modals (*might have left*) are out of scope.

## Pronunciation and IPA — please read

* Every visible English teaching word is a **word-over-IPA unit** (the IPA is centered directly beneath that word and wraps with it).
  Titles, headings, examples, options, feedback, and role instructions all use it. Punctuation has no IPA. The logo is the only exception.
  A build-time and runtime audit confirms **no word is missing IPA** and that each IPA line is centered under its word.
* Teacher-interface text (button tooltips, the clock labels *Lesson plan / Actual*, the timer caption, mode tag, toast messages, and the
  start-screen help sentence) is control chrome and is not word-over-IPA.
* **The IPA was NOT verified against Oxford Learner's Dictionaries.** That site is blocked in the build environment (the network proxy refused
  it), so I could not check it. The transcriptions in `src/js/21-ipa-data.js` follow Oxford's NAmE conventions and were entered by the lesson
  author, then cross-checked against espeak-ng output only for typos. **Please have them reviewed before teaching.** Per-word overrides use
  `[word|ipa]` markup; *could* /kʊd/ is shown in citation form and the weak form /kəd/ is taught explicitly in the pronunciation scene.
* Grammar colors are stable everywhere: who = blue, modal = magenta, *not* = orange (dashed), base verb = green, time cue = violet.
  Contrast on the paper cards is 5.3–7.0 : 1 or better, and roles are also marked by chip shape, labels, and (for answers) ✓ / ✗ marks, not color alone.

## Voice

* The narration uses **Kokoro-82M (open-source, runs locally)**: narrator `af_heart`, plus separate voices for the characters.
  No API key, subscription, or paid service was used.
* I looked for better options first. The ElevenLabs connection offered in this session did not work (requests to it were refused or returned
  errors), and Oxford and Hugging Face were unreachable, so Kokoro (from GitHub releases) was the best natural American voice actually available.
* **I cannot listen to audio.** I chose the voices from Kokoro's published quality grades and checked the pronunciation of the key words (may, might, could) as phonemes,
  clip lengths, clipping (none), and that audio playback runs. I did **not** judge how natural it sounds. Please listen to a few minutes before class.
  To change a voice, edit `FE.VOICE` in `src/js/60-runner.js`; to change a line, edit the text and re-run the commands below. Replacement audio only needs the manifest format in `src/js/05-narration.js`.
* Mouth movement follows each clip's real loudness. **Word highlighting is estimated** from pauses and word length inside each clip (not forced-aligned), so it can drift by a fraction of a second.
* Music is a quiet code-generated pad that ducks under narration; it is silent during learner-speaking activities. Ambience (rain, wind) is generated, too.

## What is not in it (no false claims)

* It does **not** use the microphone, does not hear or score learners' speech, and does not read Zoom chat. Learners answer aloud, in pairs, or in chat; the teacher clicks.
* The "Your sentence" task is a small **rule-based form checker** (it spots things like *might arrives*, *could to*, *Does she may…*, *doesn't might*, *couldn't* for uncertainty).
  It cannot judge meaning and says so on screen. It is not an AI assessor.
* The exit check and common-difficulty list contain no invented learner data.

## Rebuild and test

```bash
node tools/build.mjs --standalone      # builds release/index.html and the one-file version
node tools/test.mjs                    # automated tests (Playwright + Chromium): 57 checks
node tools/explore.mjs --shots DIR     # screenshots of every segment, plus a missing-IPA report
# After editing narration or dialogue text:
node tools/extract.mjs                 # lists every spoken line  -> tools/.lines.json
python tools/tts.py --model kokoro-v1.0.onnx --voices voices-v1.0.bin   # needs: pip install kokoro-onnx soundfile numpy
node tools/build.mjs --standalone
```

Source: `src/js` (rig `10`, IPA `20-21`, stage `25`, scenes `30-31`, explainers `40-41`, audio `50`, runner `60`, activities `70`, UI `80`,
lesson content `91-93`, boot `99`). Fonts are embedded (Source Serif 4, Source Sans 3, Noto Sans subset for IPA glyphs).
`assets/fluent_english_logo_trimmed.png` is the repository's `fluent_english_logo.png` with the white margin cropped, never stretched. The original logo files are unchanged.
